# Graficar variables y sus relaciones con `ggplot2`

En esta lección se aprende a construir tres familias de gráficos que aparecen constantemente en el análisis exploratorio de datos: el gráfico de una sola variable, el gráfico que muestra la relación entre dos o más variables, y el gráfico de dispersión llevado a su versión más completa, con color, forma, línea de ajuste y una paleta accesible. El hilo que conecta todo el recorrido es siempre el mismo: **el tipo de variable determina el gráfico**. No se elige un `geom_*` por preferencia estética, se elige porque la naturaleza del dato (categórica o numérica) exige una forma particular de representarlo.

El recorrido tiene tres momentos. En el primero se grafica una variable a la vez, para fijar la relación entre tipo de variable y `geom_*`. En el segundo se combinan dos o más variables, y el criterio para elegir el gráfico pasa a depender de qué tipos se están combinando. En el tercero se toma el caso más rico (dos variables numéricas) y se profundiza capa por capa hasta llegar a un gráfico de dispersión completo, con varias variables mapeadas a la vez.

## Categórica o numérica: la pregunta que se hace antes de graficar

Antes de escribir cualquier línea de `ggplot2` conviene mirar la variable y preguntarse qué tipo de pregunta responde. Una variable **categórica** (como el área o el género) agrupa los casos en un número limitado de etiquetas; la pregunta natural es *cuántos casos hay en cada categoría*, y eso se responde contando. Una variable **numérica continua** (como la autorregulación o la empatía) toma en principio infinitos valores dentro de un rango; la pregunta natural ya no es "cuántos hay exactamente en el valor 32.4", sino *cómo se distribuye* el valor a lo largo de ese rango.

Esa diferencia es la que separa `geom_bar()`, pensado para contar categorías, de `geom_histogram()` y `geom_density()`, pensados para describir una distribución continua. Y es también la que, más adelante, decide qué gráfico usar cuando se combinan dos variables: la combinación de tipos, no la cantidad de variables, es lo que fija el `geom_*` correcto.

# Primer momento: graficar una sola variable

## Variable categórica: `geom_bar()`

La gramática de `ggplot2` es siempre la misma: se declara un lienzo con `ggplot(datos, aes(...))` y se le agregan capas con `+`. Para una variable categórica, la capa es `geom_bar()`, que cuenta los casos de cada categoría sin que haga falta calcular esa cuenta de antemano.

```r
ggplot(df, aes(area)) +
  geom_bar() +
  labs(y = "Frecuencia", x = "Área")
```

A partir de esa misma estructura básica se puede ajustar la presentación sin cambiar el `geom_*`. Invertir los ejes es útil cuando las etiquetas de las categorías son largas y no caben en el eje horizontal:

```r
ggplot(df, aes(y = fct_infreq(area))) +
  geom_bar() +
  labs(y = "Área", x = "Frecuencia")
```

`fct_infreq()` convierte la variable en un factor ordenado según su frecuencia, de modo que las categorías aparecen de mayor a menor en vez de en orden alfabético:

```r
ggplot(df, aes(fct_infreq(area))) +
  geom_bar() +
  labs(y = "Frecuencia", x = "Área")
```

El color también se controla dentro de la misma estructura, pero conviene distinguir dos formas de usarlo. Cuando `fill` y `color` se escriben como argumentos fijos de `geom_bar()`, fuera de `aes()`, pintan todas las barras igual: `fill` colorea el relleno y `color` el borde.

```r
ggplot(df, aes(fct_infreq(area))) +
  geom_bar(fill = "red", color = "blue") +
  labs(y = "Frecuencia", x = "Área")
```

Cuando en cambio `fill` se escribe dentro de `aes()` y se le asigna una variable, deja de ser un color fijo y pasa a ser un *mapeo*: `ggplot2` le asigna un color distinto a cada categoría automáticamente.

```r
ggplot(df, aes(x = fct_infreq(area), fill = area)) +
  geom_bar(color = "black") +
  labs(y = "Frecuencia", x = "Área", fill = NULL)
```

Esta distinción (un valor fijo fuera de `aes()` frente a un mapeo dentro de `aes()`) es la base de toda la gramática de `ggplot2` y reaparece en cada gráfico de esta lección.

## Variable numérica: `geom_histogram()` y `geom_density()`

Una variable numérica continua no se cuenta por valor exacto, porque casi ningún valor se repite. En su lugar se agrupa en intervalos, llamados *bins*, y se cuenta cuántos casos caen en cada intervalo. Eso es lo que hace `geom_histogram()`.

```r
ggplot(df, aes(autorregulacion)) +
  geom_histogram(binwidth = 5) +
  labs(x = "Autorregulación", y = "Frecuencia")
```

El argumento `binwidth` define el ancho de cada intervalo, y esa elección cambia lo que el gráfico muestra: un `binwidth` demasiado angosto produce un histograma ruidoso, con muchas barras pequeñas que no dejan ver el patrón general; uno demasiado ancho aplana la distribución y esconde detalles como una segunda moda. No hay un valor único correcto; conviene probar más de uno sobre la misma variable antes de decidir.

`geom_density()` ofrece una alternativa suavizada al histograma: en lugar de barras agrupadas en intervalos, traza una curva continua que estima la forma de la distribución.

```r
ggplot(df, aes(autorregulacion)) +
  geom_density() +
  labs(title = "Gráfico de densidad",
       x = "Autorregulación", y = "Densidad")
```

# Segundo momento: relaciones entre variables

Graficar una sola variable responde qué forma tiene esa variable. Graficar dos o más variables responde si esa forma cambia según otra condición, o si dos variables numéricas se mueven juntas. El `geom_*` que corresponde depende de qué tipos de variable se están cruzando.

## Una variable numérica y una categórica

Cuando se combina una numérica con una categórica, la pregunta habitual es si la distribución de la numérica cambia entre los grupos de la categórica. El diagrama de cajas resume esa distribución (mediana, dispersión, valores atípicos) por cada grupo:

```r
ggplot(df, aes(area, autorregulacion)) +   # primero la categórica, luego la numérica
  geom_boxplot() +
  labs(y = "Autorregulación", x = "Área")
```

Una alternativa es superponer una curva de densidad por grupo, mapeando la categórica a `color`. Esto muestra no solo dónde se concentra cada grupo, sino la forma completa de su distribución, algo que el boxplot resume mucho más de lo necesario cuando hay pocos grupos:

```r
ggplot(df, aes(autorregulacion, color = area)) +
  geom_density(linewidth = 0.75) +
  labs(color = NULL, x = "Autorregulación", y = "Densidad")
```

Agregar `fill` además de `color`, con transparencia controlada por `alpha`, ayuda a leer las curvas cuando se superponen:

```r
ggplot(df, aes(autorregulacion, color = area, fill = area)) +
  geom_density(alpha = 0.5) +
  labs(color = NULL, fill = NULL,
       x = "Autorregulación", y = "Densidad",
       title = "Densidad de la autorregulación según área")
```

El boxplot conviene cuando hay que comparar rápidamente la posición central de muchos grupos; la densidad conviene cuando importa la forma de la distribución (asimetría, bimodalidad) y los grupos no son demasiados, porque más de cuatro o cinco curvas superpuestas se vuelven difíciles de leer.

## Dos variables categóricas

Cuando ambas variables son categóricas, el gráfico de barras apiladas sigue siendo el `geom_*` adecuado: es el mismo `geom_bar()` del primer momento, solo que ahora `fill` mapea una segunda variable categórica en lugar de un valor fijo, y `ggplot2` apila automáticamente las categorías dentro de cada barra.

```r
ggplot(df, aes(x = area, fill = genero)) +
  geom_bar() +
  labs(fill = NULL, x = "Área", y = "Frecuencia",
       title = "Área según género") +
  theme(plot.title = element_text(hjust = 0.5))
```

## Dos variables numéricas

Cuando ambas variables son numéricas, la pregunta cambia de "cuántos" a "cómo se relacionan los valores entre sí", y el gráfico correspondiente es el de dispersión, con un punto por caso:

```r
ggplot(df, aes(autorregulacion, empatia)) +
  geom_point()
```

## Tres o más variables

El gráfico de dispersión admite mapear variables adicionales a otras propiedades del mismo punto, como el color o la forma, sin cambiar de `geom_*`:

```r
ggplot(df, aes(autorregulacion, empatia)) +
  geom_point(aes(color = area, shape = genero))
```

Cuando esos mapeos adicionales saturan visualmente el gráfico, una paleta pensada para distinguir categorías y un tema más limpio (ambos del paquete `ggthemes`) ayudan a que el gráfico siga siendo legible:

```r
ggplot(df, aes(autorregulacion, empatia)) +
  geom_point(aes(color = area)) +
  scale_color_few() +   # paleta a juego con theme_few()
  theme_few()
```

# Tercer momento: profundizando en el gráfico de dispersión

El gráfico de dispersión es el que más se presta a construirse por capas, porque cada capa nueva agrega información sin obligar a rehacer las anteriores. Este momento retoma el caso de dos variables numéricas y lo construye paso a paso hasta llegar a la versión completa.

La capa base solo define los ejes; sin una capa de geometría, el resultado es un lienzo vacío. `ggplot(df, aes(autorregulacion, empatia))`, ejecutado solo, sin `geom_point()`, ya crea los ejes con sus nombres, pero no dibuja ningún dato. La geometría es lo que efectivamente pone los puntos sobre ese lienzo:

```r
ggplot(df,
       aes(autorregulacion,
           empatia
       )) +
  geom_point()
```

Agregar una tercera variable es tan simple como mapearla a `color` dentro del mismo `aes()`:

```r
ggplot(data = df,
       mapping = aes(autorregulacion,
                     empatia,
                     color = genero)) +
  geom_point()
```

`geom_smooth(method = lm)` agrega una capa independiente, una recta de regresión lineal, sin alterar la capa de puntos:

```r
ggplot(data = df,
       mapping = aes(autorregulacion,
                     empatia)) +
  geom_point(mapping = aes(color = genero)) +
  geom_smooth(method = lm)
```

Conviene notar dónde está escrito `color = genero` en ese código: está dentro de `geom_point()`, no en el `aes()` general de `ggplot()`. Por eso `geom_smooth()` no hereda ese mapeo y traza una sola línea de ajuste para todos los datos, en lugar de una línea por género. Si `color = genero` se moviera al `aes()` general de `ggplot()`, ambas capas heredarían el mapeo, y `geom_smooth()` trazaría una línea distinta por cada grupo.

Se puede añadir una segunda variable categórica mapeada a la forma del punto, además del color:

```r
ggplot(data = df,
       mapping = aes(autorregulacion,
                     empatia)) +
  geom_point(mapping = aes(color = area, shape = genero)) +
  geom_smooth(method = lm)
```

La versión final agrega etiquetas completas (título, subtítulo, nombres de ejes y de las leyendas de color y forma) y sustituye la paleta por defecto por `scale_color_colorblind()`, del paquete `ggthemes`, que distingue bien las categorías para personas con daltonismo:

```r
ggplot(data = df,
       mapping = aes(autorregulacion,
                     empatia)) +
  geom_point(mapping = aes(color = area, shape = genero)) +
  geom_smooth(method = lm) +
  labs(title = "Relación entre autorregulación y empatía",
       subtitle = "Ejemplo de gráfico de dispersión",
       x = "Autorregulación",
       y = "Empatía",
       color = "Área",
       shape = "Género") +
  scale_color_colorblind()
```

La elección de una paleta accesible no es un detalle decorativo del final: es parte del mismo criterio que guía toda la lección, el de elegir cada elemento del gráfico (geometría, color, forma) porque responde correctamente a la pregunta que los datos plantean, y no porque se vea bien de manera arbitraria.
